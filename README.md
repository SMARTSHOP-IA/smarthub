# smarthub

Portail des outils Smartshop, publié sur GitHub Pages : **https://smarthub.smartshop.fr**

Une seule page (`index.html`) avec un lien vers chaque outil : Sentinelle, Analyse clients, Designer, BAT,
Facturation, Smartform, Willow, Monday et Sellsy. Elle ne contient aucune donnée ; chaque outil garde sa
propre connexion Google @smartshop.fr.

Pour ajouter ou modifier un outil : éditer la carte correspondante dans `index.html`.
